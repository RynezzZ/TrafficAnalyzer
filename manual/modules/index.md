# 第三部分 功能模块

适用版本：TrafficAnalyzer v1.1.10 +

按当前要做的工作选一页。各页说明入口、关键字段、操作步骤和结果，并在用到其他模块时提供对应入口。

| 目标 | 模块 |
| --- | --- |
| 导入项目、筛选请求响应、查看详情和导出证据 | [3.1 HTTP 流量分析](./http-traffic.md) |
| 查找通信对、端口、连接行为和网络风险 | [3.2 网络层分析](./network-analysis.md) |
| 用节点连接多个输入和处理步骤 | [3.3 可视化编排](./flow-editor.md) |
| 检查请求草稿、预览报文并比较响应 | [3.4 HTTP 重放](./http-replay.md) |
| 查看告警、规则证据和行为评分 | [3.5 威胁检测](./threat-detection.md) |
| 用单条数据试运行并保存转换配方 | [3.6 CyberChef](./cyberchef.md) |
| 管理资源、调用位置、快捷键及导入导出 | [3.7 流程库](./workflow-library.md) |
| 查看 Java 序列化对象结构 | [3.8 反序列化分析](./java-deserialization.md) |
| 将 Java 类字节码转换为可阅读源码 | [3.9 Java 反编译](./java-decompiler.md) |
| 调试捕获组、替换文本或调用分组配方 | [3.10 正则工具](./regex-tool.md) |
| 检查捕获样本的解密候选 | [3.11 WebShell Fuzz](./webshell-fuzz.md) |
| 编写 Go 转换代码和共享函数 | [3.12 自定义脚本](./custom-scripts.md) |
| 配置并测试可供编排和工作台调用的 HTTP 接口 | [3.13 外部服务](./external-services.md) |

下载安装、输入类型与首次导入见[第一章](../01-getting-started.md)。导航、配置、多标签和选区快捷键见[第二章](../02-interface-and-menus.md)。
